# Веб-дашборд для инференса моделей машинного обучения

## Цель и задачи проекта

**Цель:** разработать интерактивный дашборд для воспроизводимого прогнозирования на сериализованных моделях и визуально-смыслового анализа данных.

**Задачи:**

1. Отобрать и обучить набор из шести моделей, охватывающих классические методы обучения с учителем, ансамбли (бустинг, бэггинг, стэкинг), градиентный бустинг библиотеки CatBoost и полносвязную нейронную сеть; зафиксировать метрики **R²** и сериализовать модели на диск.
2. Реализовать многостраничное веб-приложение (Streamlit): сведения о разработчике, описание данных и EDA, визуализации зависимостей, интерфейс загрузки CSV и ручного ввода с выдачей интерпретируемого результата.
3. Подготовить репозиторий с зависимостями и инструкцией по локальному запуску и развёртыванию.

## Используемый стек технологий

| Компонент                            | Назначение в проекте                                               |
| ------------------------------------ | ------------------------------------------------------------------ |
| Python 3                             | язык реализации                                                    |
| scikit-learn                         | классическая регрессия (Ridge), ансамбли, предобработка в pipeline |
| CatBoost                             | градиентный бустинг, нативное сохранение модели                    |
| TensorFlow / Keras                   | полносвязная нейронная сеть, формат `.keras`                       |
| pickle (протокол `HIGHEST_PROTOCOL`) | сериализация моделей и объектов scikit-learn                       |
| pandas / NumPy                       | работа с табличными данными и векторными операциями                |
| Matplotlib, Seaborn                  | в ноутбуке `maintaince_dataset_eda.ipynb` (разведочный анализ)     |
| Plotly                               | интерактивные графики на странице визуализаций дашборда            |
| Streamlit                            | фреймворк веб-интерфейса и маршрутизация страниц `pages/`          |

## Состав моделей (шесть лучших по R² на тесте)

| Обозначение | Тип                             | Реализация                                 | Файл                                                  |
| ----------- | ------------------------------- | ------------------------------------------ | ----------------------------------------------------- |
| ML1         | классическая модель с учителем  | `Pipeline(StandardScaler → Ridge)`         | `models/ml1_ridge_pipeline.pkl`                       |
| ML2         | ансамбль, бустинг               | `GradientBoostingRegressor`                | `models/ml2_gradient_boosting.pkl`                    |
| ML3         | продвинутый градиентный бустинг | `CatBoostRegressor`                        | `models/ml3_catboost.cbm`                             |
| ML4         | ансамбль, бэггинг               | `BaggingRegressor` (база — дерево решений) | `models/ml4_bagging.pkl`                              |
| ML5         | ансамбль, стэкинг               | `StackingRegressor`                        | `models/ml5_stacking.pkl`                             |
| ML6         | полносвязная НС                 | Keras Sequential + отдельный scaler        | `models/ml6_fcnn.keras`, `models/ml6_fcnn_scaler.pkl` |

Метрики **R²** и перечень признаков записываются в `models/metadata.json` при запуске скрипта обучения.

## Установка и запуск (локально)

1. Клонировать репозиторий и перейти в корень проекта.
2. Создать виртуальное окружение и установить зависимости:

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -U pip
   pip install -r requirements.txt
   ```

3. Обучить модели и сформировать каталог `models/` (при отсутствии готовых файлов):

   ```bash
   python scripts/train_regression_models.py
   ```

4. Запустить дашборд:

   ```bash
   streamlit run app.py
   ```

Приложение откроется в браузере; разделы **Датасет**, **Визуализации** и **Инференс** доступны в боковом меню.

## Функциональность страниц

1. **Сведения о разработчике** — ФИО, группа, тема РГР, фотография.
2. **Набор данных** — предметная область, расшифровка признаков, краткое описание EDA и предобработки.
3. **Визуализации** — интерактивные графики **Plotly** (матрица рассеяния, тепловая карта корреляций, ящики с усами, гистограммы и др.). В ноутбуке EDA дополнительно используются **Matplotlib** и **Seaborn**.
4. **Инференс** — выбор модели; загрузка файла в формате CSV с обязательными столбцами признаков; альтернативно ручной ввод нормализованных значений с ограничением диапазона [0, 1] для непрерывных признаков; вывод нормализованного прогноза и оценки температуры в кельвинах после обратного масштабирования по диапазону исходного признака `Process temperature [K]`.
